## 1. Décisions de cohérence (à appliquer partout)

| Terme | Forme retenue |
|---|---|
| Spellblaze | **Brûlure Magique** (parfois « Brûlure magique » dans classes/chats) |
| Spellhunt | **Purge Arcanique**. Spellhunter = **Traque-sorts**, pas « chasseur de sorts ». |
| Void (portail) | **Vide**. Remplacer « Néant » dans `sorcerer-fight.lua` et `sorcerer-end.lua`. |
| Ères | **Ère de la Séduction**, **Ère du Bûcher**, **Ère du Crépuscule** (majuscules) |
| Battleaxe / waraxe | battleaxe = **hache de bataille**, waraxe = **hache de guerre** (aujourd'hui mélangés avec « hache de combat ») |
| Kar'Krul / Kor'Krul | **Kar'Krul** |
| Sher'tul / Sher'Tul | **Sher'Tul** |
| Orb of command | **orbe de commandement** (pas « de commandes ») |
| Tu / vous | Un même PNJ doit garder le même registre dans une conversation (voir §4). |
| Verbes de succès | Infinitifs partout : « Devenir… », « Obtenir… », « Tuer… » |
| « energy » dans la Forteresse | « 45 **d'énergie** » (pas « 45 énergies ») |
